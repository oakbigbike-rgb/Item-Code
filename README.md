# ตรวจสอบ Item Code แจกสตรีม

หน้าเว็บรวมโค้ดแจกในไลฟ์สตรีมของ **Zone4 / WarZ / Talesrunner / Cabal PC / Cabal M**
ดึงข้อมูลตรงจาก Google Sheets ของแต่ละเกม เพื่อตอบสองคำถาม:

1. **แต่ละเกมมีโค้ดเตรียมไว้ถึงวันไหน** และมีวันไหนที่ขาด/กรอกไม่ครบ
2. **แต่ละโค้ดเติมได้จริงหรือไม่** — บันทึกผลด้วยมือ หรือให้ redeem runner เติมอัตโนมัติ

## เริ่มใช้งาน — รันตัวเดียวจบ

```bash
powershell -ExecutionPolicy Bypass -File tools\Setup.ps1
```

ติดตั้ง Node + Playwright → พาล็อกอินเว็บเติมโค้ดของแต่ละเกม → ตั้งเวลาให้รันเองทุกวัน → ซ้อมให้ดูรอบนึง
รันซ้ำได้เรื่อย ๆ ขั้นที่ทำไว้แล้วจะถูกข้าม

**สิ่งเดียวที่ต้องทำเอง** คือพิมพ์รหัสผ่านตอนล็อกอิน (สคริปต์ไม่แตะรหัสผ่านและไม่ผ่าน CAPTCHA ให้)
หลังจากนั้นระบบทำเองหมด — ถ้า session หมดอายุวันไหน จะเห็นได้จาก `redeem\status.json`
และท้าย log ของรอบนั้น แล้วล็อกอินใหม่ทุกเกมรวดเดียวด้วย:

```bash
powershell -ExecutionPolicy Bypass -File tools\Login-All.ps1 -Force
```

## อัปเดตข้อมูลโค้ดเฉย ๆ

```bash
powershell -ExecutionPolicy Bypass -File tools\Update-Codes.ps1
```

ดึงชีททั้งหมดใหม่แล้วเขียน `web\data\codes.js` + `codes.json`
จากนั้นเปิด `web\index.html` ด้วยเบราว์เซอร์ได้เลย (ไม่ต้องมีเซิร์ฟเวอร์)

อยากเปิดผ่าน http (เช่นดูจากเครื่องอื่นในวง LAN):

```bash
powershell -ExecutionPolicy Bypass -File tools\Serve.ps1
```

## ให้อัปเดตเองตลอด

```bash
powershell -ExecutionPolicy Bypass -File tools\Watch-Codes.ps1 -Check
```

ค้างไว้แล้วมันจะทำให้เองทุก 15 นาที (`-IntervalMinutes` เปลี่ยนได้):

1. ดึงชีทใหม่ทั้งหมด — **ชีทวันใหม่ที่เพิ่งสร้างถูกดึงเองอยู่แล้ว** ไม่ต้องแก้ config
2. เทียบกับรอบก่อนว่ามี **ชีทใหม่ / โค้ดใหม่ / โค้ดที่หายไป** ไหม
3. เจอโค้ดใหม่ → สั่ง redeem runner ตรวจเฉพาะเกมนั้นทันที (เฉพาะตอนใส่ `-Check`)
4. หน้า dashboard ที่เปิดค้างไว้เห็นข้อมูลใหม่เองภายใน 30 วินาที

ทุกอย่างถูกบันทึกไว้ที่ `logs\watch-<วันที่>.log` — ชีทใหม่/โค้ดใหม่/โค้ดที่หายไป
ดูย้อนหลังได้ที่ `web\data\changes.json` (ไฟล์ยังถูกเขียนอยู่ แต่ไม่ได้แสดงบนหน้าเว็บแล้ว)

> การรีเฟรชเองใช้ได้เมื่อเปิดผ่าน `Serve.ps1` เท่านั้น (เปิดแบบ `file://` เบราว์เซอร์ห้าม fetch)
> ปิดได้ที่ช็อง "อัปเดตอัตโนมัติ" มุมขวาบน

### หรือให้ Windows รันให้เอง (ไม่ต้องเปิดหน้าต่างค้างไว้)

```bash
powershell -ExecutionPolicy Bypass -File tools\Register-DailyTask.ps1 -DataOnly -At 08:00 -EveryMinutes 30
```

ตั้ง Task Scheduler ดึงชีททุก 30 นาทีตลอดวัน · `-DataOnly` = **ดึงข้อมูลอย่างเดียว ไม่เติมโค้ด**
จึงปลอดภัยกับงานเบื้องหลัง ปิดได้ด้วย `-Remove -TaskName 'ItemCode ดึงโค้ดจากชีท'`

ส่วนงานที่ **เติม+ตรวจโค้ดจริง** เป็นอีกงานแยกกัน (ต้องล็อกอินให้ครบก่อน):

```bash
powershell -ExecutionPolicy Bypass -File tools\Register-DailyTask.ps1 -At 10:00
```

> แยกกันตั้งใจ — งานที่เผาโค้ดจริงไม่ควรไปผูกกับงานดึงข้อมูลที่รันถี่ ๆ เบื้องหลัง

Zone4 ต้องผ่านด่านตรวจบอทด้วยเบราว์เซอร์จริง watcher จึงข้ามไป แล้วเตือนใน log ให้รันเอง:

```bash
node run.mjs --game=zone4 --profile --commit
```

> ใช้ Windows PowerShell 5.1 ที่ติดมากับเครื่อง ไม่ต้องติดตั้ง Node หรือ Python
> ชีททุกอันต้องตั้งค่าแชร์เป็น **ผู้ที่มีลิงก์ → ผู้อ่าน** ไม่งั้นจะได้ HTTP 401

## สิ่งที่หน้าเว็บแสดง

**การ์ดสรุปต่อเกม** — กรอกโค้ด**ครบ**ถึงวันไหน เหลืออีกกี่วัน โค้ดที่ใช้ได้ตอนนี้ ช่องที่ยังไม่กรอก
พร้อมเตือนเมื่อใกล้หมดช่วงที่เตรียมไว้ หรือมีวันที่ขาด/ไม่ครบ

> "ครบถึง" นับเฉพาะวันที่กรอกโค้ดครบทุกช่อง ถ้าชีทเตรียมไว้ไกลกว่านั้นแต่ยังกรอกไม่ครบ
> จะบอกแยกอีกบรรทัดว่า "ชีทเตรียมไว้ถึง … แต่ยังกรอกไม่ครบ"

**ปฏิทินความครอบคลุม** — ช่องละ 1 วัน ตัวเลขในช่องคือ **กรอกแล้ว / ช่องที่ชีทเตรียมไว้**
คลิกช่องได้เพื่อกรองตารางด้านล่างให้เหลือเฉพาะเกมและวันนั้น

| สี | ความหมาย |
|---|---|
| เขียว | กรอกครบทุกช่องของวันนั้น |
| เหลือง | มีโค้ดแล้วแต่ยังไม่ครบ (เช่น 1/12) |
| แดง | มีชีทแล้วแต่ยังไม่ใส่โค้ดเลย หรือไม่มีชีทของวันที่ควรมีตามรอบ |
| เทา | ไม่ใช่วันลงโค้ด หรือยังไม่ได้เตรียมชีท |

จำนวนที่ "ควรมี" ต่อวันอ่านจากจำนวนช่องในชีทจริง ไม่ใช่จากจำนวนโค้ดที่กรอกไปแล้ว —
ไม่งั้นพอวันที่กรอกไม่ครบมีมากกว่าวันที่ครบ ระบบจะเข้าใจว่านั่นคือจำนวนปกติแล้วขึ้นเขียวหมด

ระบบดูจากข้อมูลจริงว่าแต่ละเกมลงโค้ดทุกกี่วัน เช่น Cabal PC ลงวันคู่ / Cabal M ลงวันคี่
วันเว้นวันของสองเกมนี้จึงไม่ถูกนับว่า "ขาดโค้ด"

**ตารางโค้ด** — กรองตามเกม สถานะ ช่วงวันที่ ผลตรวจสอบ และค้นหาได้
ปุ่มบันทึก ผ่าน/ไม่ผ่าน (เก็บใน localStorage ของเบราว์เซอร์) และส่งออก CSV

ช่องโค้ดมีปุ่มสองปุ่ม

| ปุ่ม | ทำอะไร |
|---|---|
| **คัดลอก** | คัดลอกโค้ดอย่างเดียว |
| **ไปเติม ↗** | คัดลอกโค้ดให้ **แล้วเปิดหน้าเติมโค้ดของเกมนั้น**ในแท็บใหม่ — ไปถึงก็วางได้เลย |

การ์ดสรุปแต่ละเกมก็มีลิงก์ **หน้าเติมโค้ด ↗** อยู่ข้างลิงก์ชีท

**เตือนโค้ดซ้ำในวันเดียวกัน** — ถ้าวันไหนมีโค้ดตัวเดียวกันถูกใส่มากกว่าหนึ่งช่อง
จะขึ้นป้าย **ซ้ำในวันเดียวกัน** ที่โค้ดนั้นทุกช่อง และการ์ดสรุปบอกว่าวันไหนบ้าง เสียไปกี่ช่อง

> เป็นคนละเรื่องกับ "เดาง่าย" — อันนี้คือกรอกพลาด ก็อปทับช่องข้าง ๆ
> ปฏิทินจะขึ้นเขียวว่าครบ แต่จริง ๆ วันนั้นแจกโค้ดได้น้อยกว่าจำนวนช่องที่เตรียมไว้

**เตือนโค้ดที่ผู้เล่นเดาได้** — โค้ดที่สร้างจากรูปแบบตายตัวจะขึ้นป้าย **เดาง่าย** ข้างโค้ด
ชี้ที่ป้ายเพื่อดูว่าผิดปกติตรงไหน กรองดูทั้งชุดได้ที่ช่อง **ความเสี่ยงถูกเดา**

เตือนเมื่อเจออย่างใดอย่างหนึ่ง

- ไล่ตามแป้นพิมพ์ 5 ตัวขึ้นไป — `Q3W0E8R2TY` คือ Q-W-E-R-T-Y
- เรียงเป็นลำดับ 4 ตัวขึ้นไป — `ABCD` / `9876`
- ตัวเลขห่างเท่ากันทุกตัว 5 ตัวขึ้นไป
- **โครงเดียวกับโค้ดของวันอื่น** — ตัวอักษรตำแหน่งเดิม ต่างแค่ตัวเลข
- ต่างจากโค้ดของวันอื่นไม่เกิน 2 ตัวอักษร
- โค้ดเดียวกันถูกใช้ซ้ำอีกวัน

> **นับเฉพาะวันนี้เป็นต้นไป** — โค้ดของวันที่ผ่านไปแล้วแก้อะไรไม่ได้ ไม่ต้องเตือนให้รก
>
> **Talesrunner ไม่ตรวจเรื่องโครงและความคล้าย** — โค้ดของเกมนี้ไม่ได้ออกเป็นซีรีส์
> รูปแบบ `คำ + ตัวเลข + ตัวอักษร` ทำให้โครงซ้ำกันเองได้โดยไม่ได้แปลว่าเดาออก
> ตั้งค่าไว้ที่ `SKIP_STRUCTURE_CHECK` ใน `web/app.js` — เอา id ออกถ้าอยากให้กลับมาตรวจ
> (การตรวจ **โค้ดซ้ำเป๊ะ** ยังทำงานทุกเกมรวมถึง Talesrunner)
>
> เกณฑ์ถูกจูนกับโค้ดจริงในชีทแล้ว — ตั้งหลวมกว่านี้โค้ดสุ่มปกติจะติดร่างแหเยอะ
> วัดกับ Zone4 ที่เป็นโค้ดสุ่มจริง 384 โค้ด ไม่ติดสักโค้ด

การ์ดสรุปบอก **เป็นรายวัน** ว่าวันไหนมีโค้ดเสี่ยงกี่โค้ด เช่น `10/08/2026 3` `11/08/2026 7`
กดที่วันไหนก็ได้เพื่อกรองตารางเหลือเฉพาะโค้ดเสี่ยงของเกมและวันนั้นทันที

**ใต้โค้ดในตารางบอกว่าไปคล้ายกับของวันไหน** — `ซ้ำกับ` / `คล้ายกับ` / `โครงเดียวกับ`
ตามด้วยวันที่ซึ่งกดข้ามไปดูได้ ชี้เมาส์เพื่อดูว่าเป็นโค้ดตัวไหนบ้าง

| คำ | หมายความว่า |
|---|---|
| ซ้ำกับ | โค้ดตัวเดียวกันเป๊ะถูกใช้อีกวัน |
| คล้ายกับ | ต่างกันไม่เกิน 2 ตัวอักษร เช่น `Q1W4E7R0TZ` กับ `Q1W4E7R0TY` |
| โครงเดียวกับ | ตัวอักษรตำแหน่งเดียวกันหมด ต่างแค่ตัวเลข เช่น `REEF#V#J#N#C` โผล่ 3 วัน |

> โครงซ้ำข้ามวันคือจุดที่อันตรายที่สุด — คนที่เก็บโค้ดวันนี้ไว้ เดาของอีกวันได้โดยลองแค่ตัวเลข
> (นับเฉพาะโครงที่ซ้ำ **ข้ามวัน** โครงซ้ำภายในวันเดียวกันไม่ช่วยให้เดาวันอื่นออก จึงไม่นับ)

ผลออกไปในไฟล์ CSV ด้วย — คอลัมน์ **ความเสี่ยงถูกเดา** และ **เหตุผลที่เสี่ยง**

**บันทึกผลทีเดียวทั้งชุด** — ใต้ตัวกรองมีปุ่ม *ผ่านทั้งหมด / ไม่ผ่านทั้งหมด / ล้างผลที่กรอกเอง*
ทำงานกับ "ชุดที่กรองอยู่ตอนนี้" เช่นกด **เฉพาะวันนี้** แล้วกด *ผ่านทั้งหมด* = บันทึกผลของวันนี้ทั้งวันในคลิกเดียว

> ปุ่มพวกนี้เขียนเฉพาะผลที่กรอกเอง (localStorage) **ไม่ทับผลจาก runner**
> ซึ่งเป็นผลตรวจจริงจากหน้าเว็บ — กด *ล้างผลที่กรอกเอง* แล้วผลของ runner จะกลับมาแสดงตามเดิม

| เกม | รูปแบบชีท | ผัง |

อันไหนเป็นเดือน

## ตรวจว่าโค้ดใช้ได้จริง (redeem runner)

```bash
winget install OpenJS.NodeJS.LTS
```

> ให้รันด้วยบัญชีทดสอบเท่านั้น และผ่านโหมดซ้อมให้เรียบร้อยก่อนเติมจริง

### 1. ติดตั้งและล็อกอิน

```bash
cd redeem && npm install
```

```bash
node login.mjs cabal-pc
```

เบราว์เซอร์จะเปิดขึ้นมาให้ **คุณล็อกอินเอง** — สคริปต์ไม่แตะรหัสผ่าน ไม่ผ่าน CAPTCHA
และไม่ผ่านด่านตรวจบอทให้ ล็อกอินเสร็จกด Enter ระบบเก็บ session ไว้ที่ `redeem/auth/<gameId>.json`

Zone4 อยู่หลัง Cloudflare ต้องใช้โปรไฟล์เบราว์เซอร์ถาวรแทน:

```bash
node login.mjs zone4 --profile
```

### 2. ยืนยัน selector ของเกมที่อยู่หลังล็อกอิน

```bash
node inspect.mjs warz
```

พิมพ์รายการช่องกรอก/ปุ่มบนหน้าจริงออกมาให้ เอาไปใส่ `codeInput` / `submitButton`
ใน `config/sources.json` (ไม่กรอกไม่กดอะไรทั้งนั้น อ่านอย่างเดียว)

### 3. ซ้อมก่อน แล้วค่อยตรวจจริง

```bash
node run.mjs --game=cabal-pc --headed
```

โหมดซ้อมกรอกโค้ดลงฟอร์มแต่ **ไม่กดยืนยัน** ใช้เช็คว่า selector ถูกและยังล็อกอินอยู่

```bash
node run.mjs --game=cabal-pc --commit --limit=1
```

ตรวจจริง เริ่มโค้ดเดียวก่อนเพื่อดูว่าอ่านข้อความผลลัพธ์ได้ถูก แล้วค่อยปล่อยทั้งชุด

| ธง | ความหมาย |
|---|---|
| `--commit` | กดยืนยันจริง (ไม่ใส่ = โหมดซ้อม) |
| `--headed` | เห็นหน้าเบราว์เซอร์ขณะทำงาน |
| `--profile` | ใช้โปรไฟล์เบราว์เซอร์ถาวร (จำเป็นสำหรับ Zone4) |
| `--game=a,b` | เจาะจงเกม (ไม่ใส่ = ทุกเกม) |
| `--limit=N` | จำกัดจำนวนโค้ดต่อเกม |
| `--date=today` | เฉพาะโค้ดของวันนั้น |
| `--code=XXXX` | เฉพาะโค้ดที่ระบุ |
| `--all` | รวมโค้ดที่ยังไม่เริ่ม/หมดอายุด้วย |
| `--recheck` | ตรวจซ้ำโค้ดที่รู้ผลแล้ว |

### ผลตรวจ

| สถานะ | ความหมาย |
|---|---|
| `pass` | เติมได้ — โค้ดใช้ได้แน่นอน |
| `used` | ถูกใช้ไปแล้ว — **แปลว่าโค้ดมีจริงและใช้ได้** แค่เติมซ้ำไม่ได้ |
| `fail` | เติมไม่ได้ — โค้ดผิด/หมดอายุ/ยังไม่เริ่ม |
| `unknown` | อ่านข้อความตอบกลับไม่ออก → ดูภาพหน้าจอที่ `redeem/shots/` |
| `error` | เปิดหน้า/กดปุ่มไม่สำเร็จ |

ผลสะสมข้ามวันอยู่ที่ `redeem/results.json` และถูกคัดลอกไป `web/data/results.js`
ให้ **หน้า dashboard อ่านเองอัตโนมัติ** (ไม่ต้องกดนำเข้าแล้ว — ปุ่มนำเข้ายังใช้ได้อยู่)
รอบถัดไปจะข้ามโค้ดที่รู้ผลแล้ว จึงไม่เผาโค้ดซ้ำ

## ตรวจทุกวันอัตโนมัติ

```bash
powershell -ExecutionPolicy Bypass -File tools\Run-DailyCheck.ps1
```

ดึงชีทใหม่ → ตรวจโค้ดที่ยังไม่เคยตรวจของทุกเกม → เขียนผล → log ที่ `logs/daily-<วันที่>.log`

powershell -ExecutionPolicy Bypass -File tools\Register-DailyTask.ps1 -At 10:00

## หน้าเว็บออนไลน์ (GitHub Pages)

```bash
powershell -ExecutionPolicy Bypass -File tools\Publish-Web.ps1
```

ดึงชีทล่าสุด → สร้าง `docs\index.html` ที่**เข้ารหัสด้วย ID + รหัสผ่าน** → push ขึ้น GitHub
เว็บอัปเดตภายใน 1–2 นาทีหลัง push · ลิงก์เดิมไม่เปลี่ยน

**repo นี้เป็นสาธารณะ** ของที่ห้ามขึ้นจึงถูกกันไว้ใน `.gitignore` ทั้งหมด

| ไม่ถูก commit | เพราะ |
|---|---|
| `web/data/codes.*` | โค้ดดิบ ใครก็อ่านได้ |
| `config/sources.json` | มี docId ของชีท ซึ่งเปิดดูโค้ดทั้งหมดได้ (ใช้ `sources.example.json` เป็นแบบแทน) |
| `redeem/auth`, `redeem/profile` | session ล็อกอินเกม |
| `share/` | ไฟล์ที่มีโค้ดจริง |

`Publish-Web.ps1` ตรวจซ้ำสองชั้นก่อน push — ไล่หาโค้ดจริงในไฟล์ที่จะขึ้นเว็บ และเช็คว่าไฟล์ต้องห้าม
ไม่ได้ถูก track ถ้าเจออย่างใดอย่างหนึ่งจะหยุดทันทีไม่ push

## ความปลอดภัยของข้อมูล

```bash
powershell -ExecutionPolicy Bypass -File tools\Check-Security.ps1
```

ไล่ตรวจ 4 อย่างที่ "หลุดแล้วเดือดร้อน" แล้วบอกว่าต้องแก้อะไร ใส่ `-Fix` เพื่อให้จำกัดสิทธิ์ไฟล์ให้เอง

| ของ | ความเสี่ยง | ที่ทำไว้ |
|---|---|---|
| `redeem\auth`, `redeem\profile` | หลุด = เข้าบัญชีเกมได้ทันทีโดยไม่ต้องใช้รหัสผ่าน | จำกัดสิทธิ์ให้เฉพาะบัญชีคุณ + อยู่ใน `.gitignore` |
| ไฟล์ที่แชร์ (`share\`) | มีโค้ดจริงฝังอยู่ ใครเปิดก็ก็อปไปเติมได้ | อยู่ใน `.gitignore` · มีโหมดปิดบังโค้ดให้เลือกใช้ |
| `tools\Serve.ps1` | ถ้าเปิดรับทั้งเครือข่าย คนในวง LAN เปิดดูโค้ดได้ | ผูกกับ `localhost` เท่านั้น เครื่องอื่นเข้าไม่ได้ |
| โค้ดในชีท | Google Sheets แชร์แบบ "ใครมีลิงก์ก็ดูได้" | อยู่นอกเหนือการควบคุมของเครื่องมือนี้ — ดูหมายเหตุด้านล่าง |

### ไฟล์สำหรับส่งให้คนอื่นดู

```bash
node tools/build-share.mjs
```

ได้ `share\dashboard.html` — **มีโค้ดจริงครบพร้อมปุ่มคัดลอกและปุ่มไปเติม** เหมือนหน้าที่ใช้ทำงาน
เปิดที่ไหนก็ได้ไม่ต้องมีเซิร์ฟเวอร์ · ใครเปิดไฟล์หรือลิงก์นี้ได้ก็ก็อปโค้ดไปเติมได้ทุกตัว

### ใส่รหัสผ่านให้ไฟล์

```bash
node tools/build-share.mjs --lock
```

ถามรหัสตอนรัน แล้วได้ `share\dashboard-locked.html` ที่ต้องใส่รหัสก่อนถึงจะเห็นข้อมูล
เปิดได้ทุกเบราว์เซอร์ ไม่ต้องมีเซิร์ฟเวอร์ ใส่รหัสถูกแล้วได้ข้อมูลครบเหมือนเดิมทุกอย่าง

| | |
|---|---|
| วิธีเข้ารหัส | AES-256-GCM · คีย์มาจากรหัสผ่านด้วย PBKDF2-SHA256 310,000 รอบ |
| ในไฟล์มีอะไร | มีแต่ก้อนข้อมูลที่ถอดไม่ออก — View Source หรือ F12 ก็ไม่เจอโค้ดสักตัว |
| ลืมรหัส | เปิดไม่ได้อีกเลย ไม่มีทางกู้ ต้องสร้างไฟล์ใหม่ |

> **ทำไมไม่ทำหน้าล็อกอิน ID/รหัสผ่าน** — หน้าล็อกอินที่เช็ครหัสด้วย JavaScript ป้องกันอะไรไม่ได้
> เพราะข้อมูลยังอยู่ในไฟล์ คนเปิดกด F12 อ่านได้ตรง ๆ โดยไม่ต้องผ่านหน้าล็อกอิน
> การเข้ารหัสต่างกันตรงที่ ถ้าไม่มีรหัสผ่านก็ไม่มีข้อมูลให้อ่านเลย

สั่งแบบไม่ต้องพิมพ์รหัส (เวลาทำสคริปต์อัตโนมัติ):

```bash
$env:ITEMCODE_PASSWORD='รหัสของคุณ'; node tools/build-share.mjs --lock
```

ถ้าต้องให้คนนอกทีมดู สร้างอีกไฟล์แบบปิดบังโค้ด:

```bash
node tools/build-share.mjs --mask
```

ได้ `share\dashboard-masked.html` ที่โค้ดเหลือแค่หัวสองตัวท้ายสองตัว (`GU••-••••-••••-••D6`)
ทุกอย่างอื่นยังครบ — ปฏิทิน จำนวนโค้ด ผลตรวจ คำเตือนโค้ดเดาง่าย เพราะผลถูกคำนวณจากโค้ดจริง
ตั้งแต่ตอนสร้างไฟล์ แล้วค่อยปิดบังทีหลัง จบด้วยการไล่หาโค้ดจริงในไฟล์ซ้ำเพื่อยืนยันว่าไม่มีหลงเหลือ
(โหมดนี้จะตัดปุ่มคัดลอกกับปุ่มไปเติมออก เพราะกดแล้วได้แค่จุด)

### สิ่งที่เครื่องมือนี้ป้องกันให้ไม่ได้

- **ชีท Google** ตั้งแชร์เป็น "ใครมีลิงก์ก็ดูได้" ใครได้ลิงก์ชีทไปก็เห็นโค้ดทั้งหมด — ถ้าจะรัดกุมต้องเปลี่ยนเป็นแชร์เฉพาะคน แต่สคริปต์ดึงข้อมูลจะใช้ไม่ได้
- **ลิงก์ที่แชร์ออกไปแล้ว** ส่งต่อได้เรื่อย ๆ ถอนคืนไม่ได้
- **โปรแกรมที่รันด้วยบัญชีคุณเอง** อ่านไฟล์ทุกอย่างในโปรเจกต์ได้หมด รวมถึง session ล็อกอิน
- การจำกัดสิทธิ์ไฟล์กันได้แค่บัญชีอื่นในเครื่อง **ผู้ดูแลระบบยังเข้าถึงได้เสมอ**
